# Budget & Expense Calculator

A Python-based budget and expense management application built in VS Code to help users track income, manage daily expenses, and calculate total savings.

## Features
* Record and categorize income and expenses
* Automatically calculate remaining balance and savings
* Simple, interactive command-line interface

## How to Run the Project
1. Download or clone this repository to your computer.
2. Open the project folder in **VS Code** or a terminal.
3. Run the main Python file:
   ```bash
   python main.py
   ```
